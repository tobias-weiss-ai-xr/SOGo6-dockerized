## 🎉 OVERVIEW

The Sieve Editor provides a visual, drag-and-drop interface for creating and managing email filters, auto-replies (vacation), forwarding, and notifications — powered by the Sieve filtering engine (RFC 5228 + extensions) on the mail server.

---

## ✅ IMPLEMENTED FEATURES

### Backend (Pre-existing + Enhanced)
- ✅ `ClientSieve.py` — full Sieve client: put_script, delete_script, set_active, set_merged_filters (merges filters + vacation + forward + notify into one script), vacation/forward/notify processing
- ✅ `ModuleFilter.py` — persistence to user profile `filters` column + Sieve push on every section change
- ✅ **NEW granular filter operations**:
  - `get_filter(name)` / `set_filter(name, value)` / `delete_filter(name)`

- ✅ **NEW error constant** `ERROR_FILTER_NOT_FOUND` (S000318, 404)
